# Facescape 2020 Paper Reference

**Purpose**: Generate 3D facial models from a single face image  
**Process**:
- **3D Scanning**: 360-degree photo capture
- **3D Mesh Construction**: Multi-view images → 3D model → Normalized topology
- **Training and Rigging**: PCA model training → Blend shape-based rigging

- **Tools**: Reality Capture, Wrap 3D, Blender (+API)  
- **Language**: Python (PyQt framework)
